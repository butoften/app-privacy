简体中文

联系支持

遇到问题或有建议，请发送邮件至 service@butof.com。请提供设备型号、系统版本、App 版本、重现步骤及必要截图，不需要发送私密音频。

导入与试听

从素材库底部选择导入音频／视频文件，或从相册视频提取音频；选择保存目录后导入。点击音频图标打开试听面板，播放、暂停、停止或拖动进度。

电脑连接与上传

电脑和设备应在同一可信局域网。App 开启电脑上传后，打开当前显示的地址并输入六位配对码。保持 App 前台，允许系统本地网络权限。断开后可重新连接并选择同一文件续传；服务器重新开启后需要重新配对。

播放与后台

先为声轨绑定音频再播放。暂停保留位置，停止后从头开始；全部归零只改变音量。来电可能由系统中断，蓝牙断开时暂停以避免意外从设备扬声器出声。

找不到音频或清理空间

更新 App 后完全退出并重新打开，以加载当前素材目录。若仍提示音频文件缺失，请重新导入源文件。可在素材库删除不需要的音频，或在右上角菜单清理未完成上传。

测试反馈

通过 TestFlight 安装的用户可在 TestFlight 中提交反馈。实际支持情况以 App Store／TestFlight 显示的系统要求为准。

English

Contact

Email service@butof.com with your device model, OS version, app version, reproduction steps and relevant screenshots. You do not need to send private audio.

Import and preview

Use the controls at the bottom of the library to import audio/video files or extract audio from a photo-library video. Choose a destination folder before importing. Tap an audio icon to preview it with playback and seeking controls.

Computer upload

Connect both devices to the same trusted network. Enable computer upload in the app, open the displayed address and enter its six-digit code. Keep the app in the foreground and allow local-network access. Select the same file to resume an interrupted upload; pair again after restarting the server.

Playback

Bind media to a track before playing. Pause keeps the position; stop resets it. Zero all volumes keeps playback running silently. Calls may interrupt playback; disconnecting Bluetooth pauses playback to avoid an unexpected switch to the device speaker.

Missing files and cleanup

After updating, fully close and reopen the app to load the current media directory. Reimport the source if a file remains missing. Delete unwanted media in the library or clear incomplete uploads from the top-right menu.

Beta feedback

TestFlight testers can send feedback through TestFlight. Refer to the App Store or TestFlight for current system requirements.
